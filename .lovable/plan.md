

# اضافة حساب الشريك (الداعم) - Partner Account

## ملخص المشروع
اضافة نوع حساب ثالث "شريك/داعم" يتم تفعيله من قبل الادارة فقط (بدون تسجيل ذاتي). يستطيع الشريك متابعة رصيد دعمه ومنجزات الطلاب المسكنين على دعمه عبر لوحة معلومات مخصصة.

---

## الصفحات المطلوبة

### 1. الصفحة الرئيسية للشريك (PartnerHome)
- ترحيب بالشريك باسمه
- بطاقة الرصيد: مبلغ الدعم الاصلي، المبلغ المستهلك، المبلغ المتبقي
- تكلفة الدقيقة: 0.82 ريال (82 هللة)
- احصائيات سريعة: عدد الطلاب المسكنين، اجمالي الدقائق المستهلكة

### 2. لوحة منجزات الطلاب (PartnerDashboard)
- عرض اجمالي المنجزات لجميع الطلاب المسكنين على دعمه:
  - عدد الصفحات المحفوظة
  - عدد الاجزاء المحفوظة
  - عدد الختمات
  - عدد الجنسيات (تنوع الطلاب)
  - عدد الدقائق المستهلكة
  - عدد الاجازات والشهادات
  - عدد الجلسات المنعقدة
  - معدل الالتزام

### 3. قائمة الطلاب المسكنين (PartnerStudents)
- قائمة بالطلاب مع اسم كل طالب وتاريخ التسكين ودقائقه المستهلكة

### 4. الملف الشخصي للشريك (PartnerProfile)
- بيانات الشريك الاساسية
- تسجيل الخروج

---

## التفاصيل التقنية

### تغييرات قاعدة البيانات

**1. تحديث نوع الدور (app_role enum)**
اضافة قيمة `partner` للـ enum الموجود:
```text
ALTER TYPE public.app_role ADD VALUE 'partner';
```

**2. جدول بيانات الشريك (partner_profiles)**
```text
- id, user_id, full_name, phone, organization_name, total_support_amount (numeric)
- cost_per_minute (numeric, default 0.82)
- created_at, updated_at
- مع RLS: كل شريك يرى بياناته فقط
```

**3. جدول تسكين الطلاب على الداعم (partner_students)**
```text
- id, partner_id (user_id للشريك), student_id (user_id للطالب)
- assigned_at, status (active/inactive)
- مع RLS: الشريك يرى طلابه فقط
```

**4. جدول استهلاك الدقائق (partner_usage_logs)**
```text
- id, partner_id, student_id, minutes_used (numeric)
- session_date, description
- مع RLS: الشريك يرى سجلاته فقط
```

**5. جدول منجزات الطلاب (student_achievements)**
```text
- id, student_id, pages_memorized, parts_memorized, completions
- certificates_count, sessions_count, total_minutes
- updated_at
- مع RLS: الشريك يرى منجزات طلابه فقط
```

### تغييرات الكود

**1. تحديث AuthContext**
- اضافة `partner` كدور معترف به في النظام

**2. تحديث RoleBasedRoute**
- اضافة خاصية `partner` للتوجيه حسب الدور

**3. تحديث App.tsx**
- اضافة مسارات الشريك المحمية (`/partner-dashboard`, `/partner-students`)
- اضافة `PartnerHome` كصفحة رئيسية لدور الشريك في `RoleBasedRoute`

**4. تحديث BottomNav**
- اضافة تبويبات خاصة بالشريك: الرئيسية، المنجزات، طلابي، حسابي

**5. انشاء الصفحات الجديدة**
- `src/pages/PartnerHome.tsx` - الصفحة الرئيسية مع بطاقة الرصيد
- `src/pages/PartnerDashboard.tsx` - لوحة المنجزات بالبطاقات الاحصائية
- `src/pages/PartnerStudents.tsx` - قائمة الطلاب المسكنين
- `src/pages/PartnerProfile.tsx` - الملف الشخصي

**6. عدم اظهار خيار تسجيل كشريك**
- صفحة التسجيل تبقى كما هي (طالب او مقرئ فقط)
- حساب الشريك يُنشأ من قبل الادارة عبر قاعدة البيانات مباشرة

### تصميم الواجهة
- نفس لغة التصميم الحالية (RTL، تدرجات تركواز وذهبي، بطاقات زجاجية)
- بطاقة الرصيد تعرض شريط تقدم يوضح نسبة الاستهلاك
- بطاقات المنجزات بايقونات ملونة (ذهبي وتركواز) بشكل متناوب
